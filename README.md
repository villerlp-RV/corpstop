# Linetally website

Marketing page for Linetally, the LCRI operator console. One static page (`index.html`) plus screenshots in `assets/`, served by GitHub Pages.

- **Publish:** this site lives on the `gh-pages` branch of the Linetally app repo. Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`.
- **Point the buttons at the app:** set `APP_URL` near the bottom of `index.html` to the Linetally app's address. It is set to https://corpstop.base44.app.
- Screenshots show example data from the app, not real systems.
