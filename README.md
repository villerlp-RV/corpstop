# Corpstop website

Marketing page for Corpstop, the LCRI operator console. One static page (`index.html`) plus screenshots in `assets/`, served by GitHub Pages.

- **Publish:** this site lives on the `gh-pages` branch of the Corpstop app repo. Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`.
- **Point the buttons at the app:** set `APP_URL` near the bottom of `index.html` to the Corpstop app's address. Until then the buttons scroll to the "Get started" section.
- Screenshots show example data from the app, not real systems.
